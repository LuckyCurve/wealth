# Code standards

评审时逐条对照。这里只写「要做成什么样」；每条为什么、曾经怎么坏，见
[LESSONS.md](../LESSONS.md) 的对应小节。

## 变更范围

| 规则 | 评审看什么 |
| --- | --- |
| 一个 commit 只做一件事。 | 顺手修的东西单独提交；无关重构不进功能提交。 |
| 单一来源。 | 同一逻辑/样式/结构出现 ≥2 次就必须收敛：纯逻辑进 `logic.js`，视图模板与 helper 只留一处。改动只改那处，不在调用点各写一份。 |
| 兄弟一起改。 | 同类结构、同类入口、同一判定函数的所有调用点都查一遍：改了还是确认不用改，写进提交正文。 |
| 全路径。 | 从用户输入到落盘/渲染，把中间调用、状态变化和副作用走一遍；一个函数对不代表整个操作对。 |
| 先验形状再写。 | 外部数据（汇率、导入、存档、用户输入）先校验再进 `state`；缺失、空串、非法值、数字 0 是四件事，不合并。 |
| 失败即未知。 | 读不到、解析失败不得当成「空」「没有」或「不存在」；保留上一次的好值，覆盖前先备份。 |

## 测试

| 规则 | 评审看什么 |
| --- | --- |
| 先红后绿。 | 新测试必须先失败，失败原因与预期一致；先改实现再补测试不算。 |
| 契约写进测试。 | 单文件 SPA 的接线就是契约：单一来源、旧入口不回潮、on* 处理体可解析，都放 `test/ui-wiring.test.js`。 |
| 反验证。 | 修 bug 时把实现回退或改坏，确认新测试真的变红；不会红的测试等于没写。 |
| 单测管逻辑，E2E 管「看得见」。 | 计算样式、像素、可访问名、真实点击只有浏览器能验；判据从页面自身求值，不写死元素清单。 |
| E2E 铁律。 | 不访问外网、不用 `waitForTimeout`、seed 只在首次导航生效；细节见 [AGENTS.md](../AGENTS.md#端到端测试playwright)。 |

## UI 与无障碍

| 规则 | 评审看什么 |
| --- | --- |
| 版式单一来源。 | 同类结构共用一套 class，规格定义在 `<style>`；页面不内联重复样式，关键布局不写进 Tailwind 工具类。 |
| 指针能到，键盘也要能到。 | 行级跳转、拖拽排序、手势入口都要有 `role`/`tabindex` 与键位实现；写了焦点样式不等于路径可达。 |
| 控件有真正的名字。 | `label` 用 `for`/`id` 关联或包住控件；一个 label 管两个输入时另一个带 `aria-label`。placeholder 是示例，不是名字。 |
| 弹窗是一层真的模态。 | 有可见标题、焦点搬进来、Tab 困住、关闭后还回原处；隐藏只走 `closeModal`。 |
| 读屏器要念的话写进可访问名。 | `aria-*` 只在规范定义的宿主上生效；属性存在不等于被接收，用 AX 快照验证。 |
| 对比度 ≥ AA。 | 亮/暗两套都查；层级靠字重与颜色，不靠 `opacity` 压淡承载信息的文字。 |
| 原生控件的外观由页面接管。 | `select`/`number` 的箭头与 spinner 用 `appearance` 收掉；焦点只加环，不改元素自身形状。 |
| 表格数字右对齐并等宽。 | `num` 一档同时给右对齐与等宽数字；弹窗里的表同样适用。 |

## 数据与安全

| 规则 | 评审看什么 |
| --- | --- |
| 来自存档/导入的字符串一律转义。 | 文本、属性、`id`、`data-*` 都不例外；`id` 与 `data-target` 用同一个转义串。 |
| 迁移只有一个入口。 | `migrateState()` 同时服务本地加载与导入；新增字段先想旧数据怎么活。 |
| 改名不等于删除。 | 改引用名必须迁移引用；删除才走「失效清理」，清理范围要覆盖所有引用处。 |
| 不篡改历史。 | 快照是当时的事实，补齐/校验只作用于当前数据。 |

## 文档

- `AGENTS.md` 只放路标、命令与不可协商的流程；`LESSONS.md` 放原因与翻车证据；本文件放评审规则。
- 行为变了就同一 commit 更新对应文档；文档里不写具体数值、实现步骤和 UI 细节，那些会随代码漂移。
- 新增约定时先问：它能被测试守住吗？能就写测试；不能、且会改变决策，才写进文档。
