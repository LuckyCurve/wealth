# 资产页门槛改成「长按 + 抄写箴言」

决定：进入资产页是两段闸——指针路径先按住「资产」1 秒，抬闸后必须逐字抄写一句随机箴言才放行；
抄写对指针、键盘、读屏器同价，长按那 1 秒是键盘免掉的固定手续费。

为什么要动原来的「长按 + 确认框」：用户原话是「容易养成习惯还是没事儿就去看」。单一手势门槛
挡得住第一次，挡不住第一百次——手势的成本是熟练度可以吃掉的成本，加长按住只是把「点一下」
换成「按久一点」。而抄一句整句，每次的代价恒定，且逼人真的读完这句话本身（主题就是「短期波动不
值得看」）。顺带补掉一个暗门：旧的合成 click（`detail === 0`）直通确认框，等于「两次回车就进去」，
门槛只对用鼠标的人有效。

被否掉的路线：

- **只加长按住时长**（2 秒、3 秒）：最容易被适应，且对「真的来记一笔」同样烦。
- **冷却期 / 每日额度**：会把「确实要改一笔资产」变成惩罚，且额度天生会被当成配额用掉。
- **固定选项式的「选个理由」**：第三次就变成点同一个选项的手势记忆，等于换了个位置的手势门槛。
- **键盘也做长按**：按住 Enter 触发按键重复（keydown repeat），计时不可信；为了形式公平去伪造一条
  不可靠的路径，反而让门槛更容易被绕过。
- **允许粘贴 / 比对时归一掉空格与标点**：前者把门槛变成一次性的（抄过一次就永远 Ctrl+V），
  后者等于允许只抄骨架。两池干脆都不含标点，从源头消掉全角/半角这类无意义的失败。

代价：

- 指针路径的总成本约 15~25 秒，连「今天真要记一笔资产」也一样——这正是定价的目的，不是缺陷。
- 箴言是**文案池**而非界面词条：中英两池各用母语写、互不翻译（塞进 `I18N_EN` 只会得到译文腔，
  且会让「表里没有死词条」那条巡检误判）。两池必须句数相等、长度等价，否则换个界面语言就顺手
  改了门槛的价钱。
- 门槛不复用共用确认框（要输入框），因此 `showConfirm` 只服务备份那一个金调调用方。
